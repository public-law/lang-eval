Trajectory

Trajectory measures change over time and is not part of the overall score. Direction summarizes contributor counts, commit and merged-PR volume (recent four quarters vs the four before), new packages where a registry API exists, Hacker News story mentions, and the trailing 12-month issue close ratio (issues closed vs opened). A signal counts as up or down when it moves by at least 15%, or when the close ratio is at least 1.0 or below 0.7; otherwise it is treated as steady. Mixed means the signals disagree. The current quarter is partial. Completed-quarter counts are reused from docs/history.jsonl on later runs when they are nonzero and, for Hacker News, when the stored query still matches. A zero-to-positive change is counted only when the prior window was fully measured; unmeasured quarters are shown as a dash. Reddit and forum history is not available from those APIs for a two-year window; later weekly snapshots will fill that gap. Package growth is included only when a public API provides first-seen dates. Hacker News counts come from the Algolia HN Search API (story posts) using the query in languages.toml. Governance facts below each language are manual and sourced; they are not scored.

Aspects considered: whether the contributor base is growing or shrinking, whether commits and merged work are accelerating, whether releases arrive on a regular cadence, whether issues are being closed as fast as they open, whether the package ecosystem is adding new packages, and whether public discussion on Hacker News is rising or falling.
